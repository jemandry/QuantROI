# AI Models
## Causal AI and Neural Network Implementation

Python-based AI models for market prediction and risk assessment with >95% accuracy targets.

## Model Types

### Causal AI (CausalNex/DoWhy)
- Market causality analysis
- Feature importance identification
- Counterfactual reasoning

### Neural Networks (TensorFlow)
- Temporal Fusion Transformer (TFT)
- NVFP4 optimization
- Real-time inference

### Performance Tracking
- AI agent competition metrics
- ROI and Sharpe ratio calculation
- Risk-adjusted performance measurement

## Requirements
- Python 3.11+
- TensorFlow 2.13+
- CausalNex 0.12+
- DoWhy 0.9+
